# Writing docs

- Readers are hackathon judges and other learners. Lead with what the Lens
  does, and show it.
- Every feature section in the README has a screenshot or GIF from docs/media/.
- Diagrams are Mermaid code blocks, so GitHub renders them and they stay editable.
- Only document steps that were actually run. Mark anything unverified.
- No AI attribution, badges or watermarks.
